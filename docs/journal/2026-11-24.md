# 2026-11-24

## RAG-Antwortablauf aus der CLI ausgelagert

`rag_ablauf.py` verbindet drei Schritte: den fertigen Prompt an das
gewählte Modell senden, die Zitate gegen die übergebenen Fundstellen
prüfen und den Lauf in SQLite speichern. Die Funktion gibt die
Modellantwort, das Ergebnis der Zitatprüfung und die Lauf-ID zurück.
Die CLI entscheidet, wie sie diese Daten im Terminal anzeigt.

**Prüfung:** Der H-12-Probelauf auf dem Mac war erfolgreich. Der neue
Lauf ließ sich mit `show_rag_run.py` öffnen; Prompt, Fundstellen und
Aufrufdaten waren weiterhin abrufbar. Mit simulierten Modellantworten
wurde zusätzlich geprüft, dass unbekannte Fundstellen eine Warnung
auslösen und die reine Promptvorschau keinen Modellaufruf startet.
