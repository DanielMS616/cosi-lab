# Gespeicherte Berichte exportieren

Starte im Projektordner den Export für deinen Modellbericht mit `.venv/bin/python show_temperature_run.py 12 --export`. Ersetze `12` durch die ID deines Modelllaufs.
Bestätige die Vorschau mit `ja`. Dadurch wird der Bericht als Textdatei gespeichert. Für Lauf `12` entsteht die Datei `reports/model-run-12.txt`.
Bei `nein` entsteht keine Datei. Ein belegtes Ziel wird nicht überschrieben.
